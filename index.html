Frequently Asked Questions

Do I need an OpenAI API key to use this?
No! The extension comes with a built-in Smart Heuristic Regex engine that fills forms with extreme accuracy. The OpenAI API key is purely optional if you want advanced AI mapping.
Is my data secure?
Absolutely. All your profile data is stored locally in your browser's secure storage. It is only exported if you explicitly choose to sync it with your own personal Google Sheet.
Can I manage multiple clients?
Yes, you can create unlimited profiles. Just click the '+' icon in the extension to create a new profile for a different client or project.
